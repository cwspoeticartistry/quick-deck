★ QUICK-DECK ★
AI PRESENTATION BUILDER

Install Claude's presentation skill in 60 seconds.
Build beautiful HTML decks. Export as PDF. No paid services.

WHAT YOU NEED

  • Claude — any flavour: Claude Code (CLI), Claude Desktop, or Claude.ai
  • A modern browser — Chrome, Edge, Firefox, or Safari
  • No paid services — no API keys, no accounts, no installs beyond Claude

The skill renders decks as local HTML files you open in your browser. PDF export is Ctrl+P → Save as PDF — built into every browser.

INSTALL THE SKILL

Download the skill file first, then follow Path A (Claude Code) or Path B (Claude Desktop / .ai) below.

▼ DOWNLOAD quick-deck.md

PATH A
CLAUDE CODE (CLI)

  • Download quick-deck.md above
  • Mac / Linux:
    Save it to:
    ~/.claude/skills/quick-deck/SKILL.md
  • Windows:
    Save it to:
    %USERPROFILE%\.claude\skills\quick-deck\SKILL.md
  • Restart Claude Code (close + reopen, or type /restart)
  • In any project, type: use quick-deck
QUICK INSTALL (Mac/Linux terminal)
mkdir -p ~/.claude/skills/quick-deck
curl -o ~/.claude/skills/quick-deck/SKILL.md \
  https://cwspoeticartistry.github.io/quick-deck/quick-deck.md
QUICK INSTALL (Windows PowerShell)
$d = "$env:USERPROFILE\.claude\skills\quick-deck"
New-Item -ItemType Directory -Force -Path $d
Invoke-WebRequest https://cwspoeticartistry.github.io/quick-deck/quick-deck.md -OutFile "$d\SKILL.md"

PATH B
CLAUDE DESKTOP / CLAUDE.AI

  • Download quick-deck.md above
  • Open Claude Desktop or go to claude.ai
  • Start a new conversation
  • Click the paperclip / attachment icon and attach quick-deck.md
  • Send this message:
SEND THIS TO CLAUDE
Please follow the instructions in the attached file.

Claude will read the skill file and immediately start the presentation intake conversation.

WHAT TO EXPECT

Once the skill is active, Claude will ask you three questions:

Q1 — TYPE
"What type of presentation are you making? Do you have an existing one to redesign, an example to recreate, or do you want to build something new from scratch?"
Q2 — STYLE
"Is there a particular style you have in mind? Paste a link, browse the style gallery and paste a snippet, or just describe it in words."
Q3 — ASSETS
"Do you have any assets to include — logos, images, or an existing deck? Paste URLs or file paths, or say 'none'."

After your answers, Claude will:

  • Show you a slide-by-slide outline for approval
  • Once approved, render ./decks/<name>/v1.html to your local folder
  • Tell you exactly where the file is and how to open it
  • Keep a revision history — every version saved, never overwritten

SAVE YOUR DECK AS PDF

Once Claude renders your v1.html, open it in your browser and print to PDF:

  • Chrome / Edge: Ctrl+P → select "Save as PDF" → enable "Background graphics" → Save
  • Firefox: Ctrl+P → select "Microsoft Print to PDF" → Print
  • Mac (any browser): Cmd+P → click PDF dropdown (bottom-left) → Save as PDF

The template is built with @page CSS rules so every slide lands on its own page — no cropping, no bleed.

To iterate: just tell Claude "make slide 4 a comparison table" and it will render v2.html. Previous versions are always kept.

TROUBLESHOOTING

  • Claude says it doesn't know "quick-deck": The skill file may not have saved correctly. Check the path and restart Claude Code.
  • Fonts don't load in the HTML: You need an internet connection when opening the file (Google Fonts CDN). Once loaded, you can print to PDF offline.
  • PDF has multiple slides per page: Make sure "Background graphics" is checked and you're not in "fit to page" scaling mode. Set scale to 100%.
  • Claude Desktop / .ai doesn't follow the file: Try: "The file I attached is a skill instruction set. Please read it and start the presentation intake conversation as described."
  • Can I use my own brand colors? Yes — when Claude asks Q2, paste your HEX codes: "Use bg #0a0a0a, heading #ffffff, accent #e63946, body font Inter."

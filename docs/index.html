Install for Claude Code

  1. 1

    Download the skill file

    This single Markdown file is the entire skill. Claude reads it and knows exactly what to do.

    Download quick-deck.md
  2. 2

    Move it to your skills folder

    Rename the file to SKILL.md and place it in the Claude Code skills folder for your operating system:

    ~/.claude/skills/quick-deck/SKILL.md
    %USERPROFILE%\.claude\skills\quick-deck\SKILL.md

    You may need to create the skills/quick-deck/ folder first.

  3. 3

    Open Claude Code and trigger the skill

    Restart Claude Code if it was already open, then type this phrase in any conversation:

    use quick-deck

    Claude will greet you with the first question immediately.

Install for Claude Desktop & Claude.ai

  1. 1

    Download the skill file

    This single Markdown file is the entire skill. Claude reads it and knows exactly what to do.

    Download quick-deck.md
  2. 2

    Start a new conversation and attach the file

    In Claude Desktop or on Claude.ai, open a fresh conversation. Use the paperclip or attachment button to attach the quick-deck.md file you just downloaded.

  3. 3

    Send this message to activate

    With the file attached, send exactly this message:

    Please follow the instructions in the attached file.

    Claude will greet you with the first question immediately. You can reuse the same attached file in future conversations.

Export

Save your deck as a PDF.

Every deck renders to a local HTML file. One print command turns it into a crisp, one-slide-per-page PDF.

01
Open the deck
Claude tells you the file path. Open it directly in Chrome, Edge, Firefox, or Safari.
02
Print to PDF
Press Ctrl+P (or ⌘P on Mac). Change the destination to "Save as PDF".
03
Check page settings
Set paper size to Custom (1280×720px) or Landscape A4. Margins: None. Background graphics: On.
04
Save
Each slide is exactly one page. The deck renders at full fidelity — fonts, colours, and layout preserved.
FAQ

Common questions.

Does this work with Claude.ai (the web version)?
Yes. Download quick-deck.md, open a new conversation on Claude.ai, attach the file, and send "Please follow the instructions in the attached file." The deck is saved to your local machine when Claude writes the HTML output (Claude.ai's file download feature). This is Path B in the install guide above.
Do I need a paid Claude subscription?
You need whatever Claude access you already have — free or paid. quick-deck uses no external services or APIs. The only limit is your Claude session's context window, which free tiers handle fine for most decks.
Can I update an existing presentation instead of building from scratch?
Yes. When Claude asks "What type of presentation?" (Question 1), say you have an existing one and attach it. Claude will read the current slides and apply changes — rewriting copy, restyling, or adding slides — then save a new version file. The original is never overwritten.
Where does the deck file go? Do I need a local server?
Claude saves the deck as a plain .html file to your current working directory (or wherever you tell it to). No server needed — just open the file directly in your browser. The CSS and fonts are either inlined or loaded from a CDN, so it works completely offline after first load.
